# Agent Usage Guidelines

This project maintains specialized agent definitions to guide development in specific domains. When working on tasks related to these domains, you must refer to and follow the instructions in the corresponding agent file.

## Agent Definitions Location

All agent definitions are stored in the `docs/agents/` directory:

- `docs/agents/agent.md`: General development guidelines and project-wide principles.
- `docs/agents/dba.md`: Database administration, schema design, and SQLDelight best practices.
- `docs/agents/qa.md`: Quality assurance, testing strategies, and bug reporting.
- `docs/agents/gis-agent.md`: GIS-specific nuances, coordinate systems, mapping licenses, and spatial data handling.

## How to Use

1. **Context Awareness**: Before starting a task, identify if it falls under any of the specialized domains above.
2. **Consultation**: Read the relevant agent definition(s) in `docs/agents/` to ensure compliance with domain-specific standards and best practices.
3. **Consistency**: Ensure all new code and documentation align with the specialized instructions provided by these agents.
